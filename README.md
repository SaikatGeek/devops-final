🚀 *Project: ShopLite on AWS — Build, Ship, Observe & Recover*

You'll work on building and operating a production-style e-commerce application, covering everything from application development and infrastructure setup to Kubernetes, CI/CD, monitoring, and troubleshooting.

📌 *Project Tasks*

1️⃣ **Application Development:** Build a frontend, REST API, PostgreSQL database, Redis queue, and background worker.

2️⃣ **Docker:** Containerize the application using Dockerfiles and Docker Compose, with automated smoke tests.

3️⃣ **Linux Administration:** Work on SSH security, permissions, systemd backup services, and firewall rules.

4️⃣ **AWS & Terraform:** Provision AWS infrastructure using Terraform and configure servers and Kubernetes with Ansible.

5️⃣ **Kubernetes:** Deploy the application using Helm, including health checks, autoscaling, persistent storage, and network policies.

6️⃣ **Observability:** Set up Prometheus, Grafana, Loki, and Tempo for monitoring, logs, traces, dashboards, and alerts.

7️⃣ **CI/CD & GitOps:** Automate testing, security scanning, image publishing, and deployment using GitHub Actions and ArgoCD.

8️⃣ **Chaos Engineering & RCA:** Investigate a hidden production issue, identify its root cause, document your findings, and recover the system through GitOps.
